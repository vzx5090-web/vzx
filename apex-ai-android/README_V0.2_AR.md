# APEX AI Android V0.2

## ما الجديد؟
- معالجة مشكلة تشغيل المهام: لم نعد ننتظر Future.get() داخل عامل WorkManager.
- تمرير معرف المهمة فقط إلى WorkManager؛ النصوص الطويلة محفوظة محلياً لتفادي حد WorkManager Data.
- دعم عنوان API متوافق مع OpenAI + اسم نموذج + API Key اختياري.
- تشفير مفتاح API بواسطة Android Keystore (AES-GCM).
- تعليمات ثابتة للمستخدم تُضاف إلى System Prompt لكل مهمة.
- بحث ويب DuckDuckGo بدون مفتاح وحفظ عنوان/مقتطف/رابط كل مصدر في SQLite.
- ذاكرة دائمة لكل مشروع وذاكرة عامة؛ تحفظ البرومبتات والخطط والمخرجات والمراجعات والدروس.
- استرجاع آخر ذكريات المشروع قبل بدء التوليد.
- جولات نقد وتحسين متكررة.
- إضافة إشعار أمامي محدد النوع dataSync لمهام WorkManager الطويلة.

## إعداد افتراضي جاهز
- API Base: https://oai.endpoints.kepler.ai.cloud.ovh.net/v1
- Model: code_chat@latest
- API key: اختياري. يسمح OVH AI Endpoints بطلبات مجهولة لكن بقيود أشد؛ إضافة مفتاحك اختيارية وقد ترفع حد الطلبات وفق سياسة المزود.
- البحث يستخدم DuckDuckGo HTML بدون مفتاح؛ قد يمنع محرك البحث بعض الطلبات أو يغير تنسيق الصفحة.

## التشغيل
لا يحتاج APEX إلى Termux أو إعداد نموذج. افتح التطبيق واكتب فكرة لعبتك. يمكن إدخال مفتاح API اختياري من إعدادات مزود الخدمة.

## ما معنى التعلّم؟
- تُحفظ المعلومات تلقائياً في SQLite على الجهاز وتبقى بعد إغلاق التطبيق وإعادة تشغيله.
- يسترجع APEX هذه المعلومات ويضعها ضمن سياق طلبات النموذج (ذاكرة/RAG).
- التعليمات الدائمة لا تُغير أوزان النموذج.
- هذا الإصدار لا ينفذ Fine-tuning فعلياً ولا يغير أوزان النموذج. لتحسين الأوزان يجب جمع بيانات عالية الجودة وتصديرها ثم تدريب نموذج مناسب في بيئة GPU منفصلة مع تحقق من الجودة.

## حدود واستثناءات
- نتائج البحث تُحفظ كمقتطفات وروابط، وليست نسخاً كاملة من الصفحات.
- لا يُنفذ كود Luau داخل Roblox Studio، ولا ينشر لعبة.
- مهام Android الطويلة قد تتأثر بتوفير النظام والبطارية. WorkManager يحافظ على المهمة قدر الإمكان ويستعيدها وفق قيود Android، لكنه لا يضمن استمرار التنفيذ عند كل قيود الشركة المصنعة أو فقد الاتصال.
- لا ترسل مفاتيح API لأي شخص. التطبيق يخزن المفتاح مشفراً محلياً لكنه يحتاج حماية جهازك.
