# APEX AI Android V0.2.2 — Gemini default

## إعداد افتراضي جاهز
- API Base: https://generativelanguage.googleapis.com/v1beta/openai
- Model: gemini-3.8-flash
- أدخل Gemini API Key مرة واحدة داخل التطبيق. سيُشفّر محلياً باستخدام Android Keystore.
- لا ترسل مفتاح API في المحادثة أو في تعليمات المشروع.
- الواجهة مبنية على واجهة Chat Completions المتوافقة مع OpenAI التي توثقها Google.

## ما الذي يفعله النظام؟
- تخطيط مهمة لعبة Roblox.
- بحث ويب DuckDuckGo وحفظ المقتطفات وروابط المصادر.
- إنشاء ملفات Luau ومساراتها.
- مراجعة نقدية ثم جولات تحسين.
- تعليمات دائمة، برومبت لكل مهمة، ذاكرة دائمة واسترجاع للمعلومات من مهام سابقة.
- تخزين المشاريع والمعرفة محلياً في SQLite بعد إغلاق التطبيق.

## تنبيه حول التدريب
الذاكرة والاسترجاع والنقد والتحسين لا تغير أوزان Gemini. التدريب الحقيقي Fine-tuning يحتاج بيانات تدريب منظمة وبيئة GPU وخط تدريب منفصل. هذه النسخة لا تدّعي Fine-tuning.

## القيود
- البحث يحفظ مقتطفات وروابط ولا ينزّل كل صفحات الويب.
- الكود الناتج لا يُشغّل داخل Roblox Studio ولا تُنشر لعبة تلقائياً.
- استمرار المهام يعتمد على قيود Android والشبكة وإدارة البطارية.
