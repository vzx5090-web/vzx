# Octane Studio Mobile — Android Standalone

نسخة محرر إنشاء عوالم ثلاثية الأبعاد تعمل كتطبيق Android مستقل. لا تحتاج إلى كمبيوتر أو OctanePlayerLauncher.exe أو خدمة تحكم عن بُعد لتشغيل المحرر.

## ما الذي يعمل محلياً على الهاتف؟
- عارض مشهد ثلاثي الأبعاد باستخدام WebGL مضمّن داخل التطبيق.
- اختيار العناصر وإضافتها وتحريكها وتدويرها وتغيير حجمها.
- Explorer وProperties وشجرة عناصر المشروع.
- أجزاء Part وSpawnLocation وModel وFolder وواجهات ScreenGui وFrame وTextLabel وTextButton.
- محرر Luau وتشغيل السكربتات عبر مكتبة Luau أصلية مضمّنة لمعمارية ARM64.
- طبقة توافق محلية لمجموعة من واجهات Roblox الشائعة، مع اختبار Luau آلي.
- Playtest محلي مبسط مع تحكم لمس للشخصية.
- حفظ تلقائي/يدوي في مساحة التطبيق الخاصة، وفتح/تصدير ملفات المشروع عبر منتقي ملفات Android.
- استيراد صيغ JSON وRBXMX وRBXLX ضمن حدود المحول الموجود، وتصدير Studio JSON وRBXMX.

## ما الذي لا يدّعي هذا المشروع أنه يفعله؟
هذا ليس تطبيق Roblox Studio الرسمي ولا يحتوي على محرك Roblox الإنتاجي أو خوادم Roblox. طبقة Luau تنفّذ مجموعة توافق محددة داخل معاينة محلية؛ لا تكافئ كل الخدمات والفيزياء والشبكات والـMarketplace أو بيئة السيرفر الرسمية. تصدير RBXMX لا يعني إنشاء ملف تجربة Roblox منشور جاهزاً.

## العمل دون إنترنت
يمكن فتح المحرر وبناء المشهد وتشغيل طبقة Luau المحلية وحفظ المشروع دون اتصال. مساعد Gemini اختياري ويتطلب اتصالاً بالإنترنت ومفتاح API؛ عدم استخدامه لا يمنع أدوات التحرير المحلية.

## المتطلبات
- Android 8.0 أو أحدث (minSdk 26).
- جهاز ARM64 / arm64-v8a.
- يفضّل ذاكرة 6 GB أو أكثر لمشاهد أكبر.

## البناء
يتطلب JDK 17 وAndroid SDK 36 وNDK 28.2.13676358 وCMake 3.22.1 وGradle 9.6.0:
```bash
gradle --no-daemon :app:assembleDebug
```

معرّف التطبيق: `com.octane.studio.mobile`.
نسخة Android: `1.0.0-mobile-preview`.
